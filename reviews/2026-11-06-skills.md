## Current-source updates

- [Vite release support](https://vite.dev/releases) and [runtime requirements](https://vite.dev/guide/): replaced the unsupported Vite 5 scaffold default with supported compatible Vite 7.3; did not migrate existing projects.
- [typescript-eslint compatibility](https://typescript-eslint.io/users/dependency-versions/): generated lint dependencies/configuration agree with the supported ESLint/TypeScript range and Node requirement.
- [Supabase API keys](https://supabase.com/docs/guides/getting-started/api-keys): distinguish publishable and secret keys and their legacy counterparts; new browser clients use publishable keys.
- [React Router routing](https://reactrouter.com/start/declarative/routing) and [Playwright navigation readiness](https://playwright.dev/docs/api/class-page#page-goto): parent paths/layouts/basenames and explicit visible-content readiness inform the updated helpers.
- [Git diff format](https://git-scm.com/docs/git-diff): NUL-delimited names avoid filename quoting ambiguities.
- [Python plistlib](https://docs.python.org/3/library/plistlib.html): XML and binary entitlements are parsed as structured values.
- [scikit-learn cross-validation](https://scikit-learn.org/stable/modules/cross_validation.html) and [model persistence](https://scikit-learn.org/stable/model_persistence.html): expose protocol assumptions and distinguish trusted artifact-loading choices.
- [FastAPI CORS](https://fastapi.tiangolo.com/tutorial/cors/) and [Google robots specification](https://developers.google.com/crawling/docs/robots-txt/robots-txt-spec): corrected credentialed-origin examples and crawler-rule interpretation.
- Provider/model guidance now points to current official catalogs and schemas instead of frozen fallback-model recipes. Exact links are in the affected skill references.
