# Backtest Report Structure

Fill this structure to produce `reports/backtest-<strategy-name>.md`. Keep the H2
section order and headings exactly as below. The **Metrics** table is pasted
verbatim from `scripts/compute-metrics.py` — never retype numbers.

Provenance labels (put one per factual line where it matters):

- `Confirmed from code` — the value comes from the metrics script or a cited file line.
- `Strongly inferred` — a reasoned interpretation of computed numbers or code.
- `Not found` — the fact could not be located; do not guess.

---

## Rules for filling it

1. Run `scripts/compute-metrics.py` first; paste its table into **Metrics** unchanged.
2. Every number outside the table must cite the metrics JSON or a code line.
3. Attach a provenance label to each factual line; use `Not found` rather than inventing.
4. **Known Gaps** is a prioritized `- [ ]` checklist, most launch-blocking first.
5. If any category (cost model, OOS split, robustness) was not addressed, say so plainly and add it to Known Gaps — do not imply it was done.
6. Output only this one file. No prose, chat, or extra files outside it.
